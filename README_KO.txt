GitHub Pages 업로드용 전체 프로젝트입니다. ZIP 압축을 풀고 내부 파일을 저장소의 배포 루트에 업로드하세요.

주요 변경 사항
1. 선택한 테마 바탕색은 앱의 넓은 작업 캔버스에만 적용하고, 기존 도구 카드·설정 패널·입력/가중치 조절 표면은 중립 회색/흰색을 유지합니다. 패턴의 선 사이 색을 작업 캔버스 색상으로 사용하지 않습니다.
2. 프롬프트 편집기에 문장 안쪽까지 검색하는 일괄 치환을 추가했습니다. 찾을 표현마다 매치 위치를 표시하고, 개별 체크로 치환 여부를 정할 수 있습니다.
3. 페어 상세의 PAIR GALLERY와 IMAGE LOG EXCERPTS를 하나의 갤러리 탭 구성으로 묶었습니다. 이미지 로그는 기존과 같이 Pair Gallery의 공통 업로드/미리보기/비율/크롭 흐름을 사용합니다.
4. 페어별 카테고리를 등록하고 다음 게시글에서도 다시 선택할 수 있도록 페어 레코드의 선택 필드로 저장합니다. 기존 게시글에서 사용한 카테고리도 목록에 포함합니다.
5. 사진 및 이미지 로그 발췌 작성 시 출처명과 링크를 선택적으로 입력할 수 있습니다. 출처 표시는 상세 화면 맨 아래에 작은 글씨로 표시됩니다.

배포 주의
- 기존 GitHub Pages 파일을 백업한 다음 압축 내부 7개 파일을 저장소 루트에 업로드하고 커밋하세요.
- 기존 LocalStorage 및 IndexedDB 데이터는 초기화하지 마세요.
- 브라우저에 저장된 기존 데이터는 그대로 유지되며, 페어 카테고리는 기존 페어 레코드에 선택 필드로 추가됩니다.
- 실제 사용자 데이터로 업로드/저장/새로고침을 확인하기 전에 JSON/데이터 백업을 권장합니다.

[v69 수정 사항]
- 테마 저장 초기화 순서 오류 수정: 저장된 테마를 읽은 뒤에만 자동 저장을 허용합니다.
- 기존 작업 카드와 가중치 입력 영역의 색상 강제 덮어쓰기를 제거했습니다.
- IndexedDB 읽기 실패 시 기존 자료가 삭제된 것처럼 조용히 빈 목록만 보여주지 않고, 경고와 재연결 버튼을 표시합니다.
- 마지막으로 연 탭을 공간별로 기억합니다.
- 기존 버전의 IndexedDB가 다른 탭에 의해 잠긴 경우 즉시 실패 처리하지 않고 대기하며, 마이그레이션 실패 시 완료 표시를 기록하지 않아 다음 접속에서 안전하게 재시도합니다.
- LocalStorage/IndexedDB 키와 데이터베이스 이름은 변경하지 않았습니다.
