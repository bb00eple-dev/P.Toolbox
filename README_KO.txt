이번 수정 범위
1. 제공된 시안의 실제 화면색을 기준으로 작업 캔버스를 분리했습니다.
   - 바깥 배경: #FFF6F7
   - 타이틀바: #AF5862
   - 창 프레임 및 홈 작업 바탕: #C0C0C0
   - PROMPT RANDOM / OUTFIT RANDOM / PROMPT EDITOR 작업 캔버스: #D2D2D2
   - 내비게이션: #F3EFE7
   - 홈 종이 영역: #FEFDFB
   - 패턴 선: #EED2E0
2. 위의 넓은 작업 캔버스만 배경색을 지정했습니다. 기존 카드, 버튼, 셀렉트, 입력창, 가중치 조절 항목의 색상 규칙은 덮어쓰지 않습니다.
3. 테마는 현재 공간에 저장된 값을 먼저 읽습니다. 시작 과정에서 기본 테마를 저장해 사용자 값을 덮어쓰지 않습니다. 중간 버전에서 알려진 잘못된 기본 팔레트만 시안 색상으로 보정해 저장합니다.
4. 기존 LocalStorage 접두사, 공간 인덱스 키, IndexedDB 데이터베이스 이름과 버전은 유지합니다. 현재 공간의 구버전 설정 키는 빈 배열/객체가 이미 있더라도 ID/값 기준으로 병합합니다.
5. 현재 공간 해시와 일치하는 구버전 IndexedDB 보관함을 확인하고, 누락된 ID만 복사합니다. 전역 보관함은 원래 연결된 공간에만 병합합니다. 원본 데이터베이스와 원본 LocalStorage 키는 삭제하지 않습니다.
6. IndexedDB 연결 또는 구버전 저장소 읽기에 실패하면 빈 보관함으로 성공 처리하지 않습니다. 다른 저장소로 조용히 전환해 새 데이터를 쓰지도 않습니다.
7. 서비스 워커 캐시 이름을 v71으로 갱신했습니다. 이는 앱 파일 캐시 교체이며 LocalStorage/IndexedDB와 무관합니다.

배포
